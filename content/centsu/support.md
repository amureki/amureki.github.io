For help with Centsu, email [hi@amureki.me](mailto:hi@amureki.me?subject=Centsu%20Support). Include your iOS version and a short description of the problem. Remove financial details from screenshots and do not attach your ledger.

## Files and synchronization

Changes save on your iPhone first. If you selected a shared ledger, synchronization runs while the app is open. In Settings, use **Sync now** to retry and **Sync details** to inspect the current status. An upload status does not confirm that a file has arrived on another device.

If both the phone and shared file have changed, export the phone copy before resolving the differences. Centsu does not merge conflicting edits automatically.

## Recovery copies

Previous ledger versions are kept in **Centsu/Recovery**, available through the Files app. To restore a copy, use **Settings → Import ledger**. Export your current ledger first if you need to keep later changes.

For details about local storage, cloud files, and deletion, read the [privacy policy](@/centsu/privacy.md).
