Centsu is a personal money tracker for iPhone, built by Rust Saiargaliev for his own daily use.

It is a manual ledger for income, expenses, transfers, and recurring payments. Entries save locally and work offline. You can import and export a JSON ledger and optionally synchronize a selected file through iCloud Drive while the app is open.

This page provides [privacy information](@/centsu/privacy.md) and [support](@/centsu/support.md).
